# Guides

There's a lot of guides in here. You do **not** need to master everything before getting started! Here is a curated list of resources to help you learn the fundamentals.

## General Guides

### Git & GitHub

Learn how to manage code changes, work with branches, and collaborate using GitHub.

- [Nebula GitHub Workshop](https://github.com/UTDNebula/git-workshop)
- [GitHub Skills Git Introduction](https://skills.github.com/)

### Go (Golang)

Learn the Go programming language and the fundamentals needed to work on our codebase.

- [A Tour of Go](https://go.dev/tour/) - Official interactive introduction to Go syntax, data structures, and concurrency.
- [Go by Example](https://gobyexample.com/) - Hands-on, concise Go examples. Very good for quick reference while working on issues.
- [Learn Go in Y Minutes](https://learnxinyminutes.com/docs/go/) - Quick visual cheat sheet for developers who want a fast syntax refresher.

### Docker & Containers

Learn how to build, run, and manage applications using Docker containers.

- [Docker Documentation: Orientation and Setup](https://docs.docker.com/get-started/) - Official step-by-step introduction to images and containers.

### Web Basics

Learn how websites are structured and how HTML and CSS work together.

- [MDN Web Docs: HTML & DOM Basics](https://developer.mozilla.org/en-US/docs/Learn/HTML) - Learn how web pages are structured with elements, tags, and attributes.
- [MDN Web Docs: CSS Selectors](https://developer.mozilla.org/en-US/docs/Learn/CSS/Building_blocks/Selectors) - Understand class, ID, and attribute selectors used to find page elements.

## Scraper Libraries

ChromeDP lets us control a headless Chrome browser to interact with and scrape dynamic websites.

### ChromeDP

- [Headless Browser Tutorial](https://www.zenrows.com/blog/chromedp) - Good introduction to ChromeDP.
- [ChromeDP Documentation & Examples](https://github.com/chromedp/examples) - Examples for browser automation and scraping dynamic JavaScript pages in Go.

## Parser Libraries

### Goquery

Goquery lets us parse and query HTML, making it easier to extract data from web pages.

- [Goquery Guide](https://www.zenrows.com/blog/goquery) - Excellent follow-up to the ChromeDP Browser Tutorial.
- [Goquery Guide](https://zetcode.com/golang/goquery/) - More in-depth guide to Goquery.

## Uploader Libraries

### MongoDB Go Driver

The MongoDB Go Driver lets us store and retrieve scraped data from MongoDB using Go.

- [MongoDB Go Driver Official Docs](https://www.mongodb.com/docs/drivers/go/current/) - Official documentation for using MongoDB with go
